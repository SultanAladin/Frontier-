Tyre lattice study

Steps 3 & 4 before the C++ change: the physics runs on a coarse XPBD lattice (CPU, same constraint set as XPBDSoftTyre: spokes, shear, hoop/lateral/diagonal edges, gas, ground, bristle), and the GPU skins the 9×128 render tyre from it in the vertex shader — the Chaos split. The body touches the ground through a baked lower-envelope hull, not every vertex.

Reading it

Change the solver lattice and watch the render tyre: it stays 9×128 and smooth because the GPU interpolates the coarse nodes and adds each vertex's constant rest offset in the material frame. Fz should stay within a few % across lattices; ms should fall roughly with node count. The window slider greys out the nodes that ride the hub rigidly. Drag to orbit, wheel to zoom.
