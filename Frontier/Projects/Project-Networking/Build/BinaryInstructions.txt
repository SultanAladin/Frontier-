PROJECT-NETWORKING - NATIVE WINDOWS LOGIN APP

1. Extract the whole ZIP.
2. Double-click NetworkingLogin.exe in the top-level folder.
   This opens a Dear ImGui + GLFW window. No console, commands, or launcher script.
   Leave the included EOSSDK-Win64-Shipping.dll beside it.
3. For development login, start Epic's Developer Authentication Tool on port 6547,
   sign in with an authorized development account, and save its credential as PlayerOne.
   Keep the tool running. It is separate from the included EOS runtime.
4. In the app, choose Developer Auth Tool, enter the saved credential NAME and your
   rotated EOS client secret in the masked field, then click Log in with Epic.
   The secret is not written to the activity log or saved by the UI.
5. Watch the connection status. Save log opens a native Save dialog for redacted evidence.
   Cancel login stops a pending attempt. You must re-enter the secret to retry.

If Connect reports account_creation_required, confirm this is a genuinely NEW Dev
player before selecting Allow NEW Dev product-user creation and retrying. This permits
a real PUID creation; it is not a workaround for identity linking.

Client configuration allows overriding the Client ID if you replaced the entire client.
Rotating only its secret does not require changing the Client ID.

Epic Account Portal is also selectable, but on Windows it requires the EOS redistributable
and launch through EOS Bootstrapper. The app reports readiness errors rather than pretending
to log in. Developer Authentication Tool is the simplest first development test.

SUCCESS requires the green Auth + Connect verified status and the actual activity entry:
  LOGIN_VERIFIED auth=success connect=success
A successful SDK check is NOT a player login.

WindowsChecks.log, WindowChecks.log and WindowProof.bmp are CI evidence for SDK startup,
window rendering, and missing-credential rejection. No player authentication occurred in CI.
The app remains a one-shot diagnostic, not a persistent multiplayer session.

If Windows reports missing VCRUNTIME140/MSVCP140 libraries, install Microsoft's official
Visual C++ 2015-2022 Redistributable (x64). Never download individual DLLs from DLL sites.

The optional project DLL in Build/Output is for your existing Frontier.exe. This package
is not a complete engine build. The old console diagnostic remains a CI-only source target
and is not included in this GUI package. See INSTRUCTIONS.md for developer build details.
